十五二十 遊戲規則

🎯 遊戲勝負機制

預測兩人「手的點數總和」。率先贏得 3 回合 者獲得最終大勝！

🖐️ 你的模型類別映射 (Classes)

  • • Class 1: 未開始/準備中 (無效手勢，需重新比)
  • • Class 2: 雙手收拳 = 0 點
  • • Class 3: 右手掌 + 左手拳 = 5 點
  • • Class 4: 左手掌 + 右手拳 = 5 點
  • • Class 5 & 6: 雙手皆出掌 = 10 點

⚔️ 勝負結算原則

  • 點數總和可能為：0, 5, 10, 15, 20。
  • 若你的「喊號」等於實際總和，且電腦沒喊中 -> 玩家得分！
  • 若電腦的「喊號」等於實際總和，且你沒喊中 -> 電腦得分！
  • 若兩人都喊中或都沒喊中 -> 平手再接再勵！
